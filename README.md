# 基于 ESP32-S3 CAM 的手掌追踪自平衡车

> Palm-Tracking Self-Balancing Car —— 帧差法 + 卡尔曼多目标追踪 × STM32 串级 PID

## 项目简介

在自平衡车（STM32F103，串级 PID 控制）上搭载 ESP32-S3 CAM 视觉模块，通过**帧差法运动检测 + BFS 连通域分析 + 卡尔曼多目标跟踪**实时锁定人的手掌，将目标质心与面积通过串口发送给主控，实现**手掌引导式跟随**：手掌在 30~40cm 处停车对正，更远则自动接近，手掌移出画面则原地静止等待。

## 系统架构

```
┌─────────────────────────────┐     UART 115200      ┌──────────────────────────────┐
│  ESP32-S3 CAM（幻尔科技）    │  MOTION:n;id,x,y,     │  STM32F103C8T6（平衡车主控）   │
│                             │  area,miss  ───────▶ │  USART1 中断解析 → 目标锁定   │
│  灰度帧 → 帧差 → 二值掩膜    │                       │                              │
│  → BFS 连通域 → 卡尔曼跟踪   │       GND 共地        │  视觉外环：                 │
│                             │                       │  面积定速 + 质心转向         │
│                             │                       │  → 速度环 → 角度环（串级）    │
│                             │                       │  → 转向环 → 电机 PWM          │
└─────────────────────────────┘                       └──────────────────────────────┘
```

## 接线

核心接线（详见 `docs/接线说明.md`）：

| 视觉模块四针口 | 平衡车板 |
|----------------|----------|

## 软件说明

- `esp32_cam/frame_diff_test.ino` —— 视觉固件：320×240 灰度、2×2 降采样 160×120 网格、帧差阈值 30、BFS 连通域（面积 ≥80px²）、卡尔曼恒速模型 + 最近邻关联（4 目标上限，miss≥8 删除），输出 `MOTION:n;id,x,y,area,miss` @115200；含摄像头掉线自动重启（CAM_RESTART）
- `stm32_balance_car/` —— 主控固件：USART1 中断解析、目标锁定策略（miss<5 维持锁定，否则选最大面积）、300ms 掉线保护；视觉外环输出速度环/转向环目标值，与原串级 PID 无缝衔接

## 使用步骤

1. 烧录 ESP32（Arduino IDE，板型 ESP32S3 Dev Module，PSRAM 选 OPI）
2. 烧录 STM32（Keil MDK）
3. 按 **K1** 启动平衡，按 **K2** 进入视觉追踪模式
4. 手掌在镜头前晃动（帧差法需目标保持运动），车即跟随；手掌移至 30~40cm 内停车对正

> 源码均为 UTF-8 编码：若 Keil 中中文注释乱码，在 Edit → Configuration → Editor → Encoding 选 UTF-8 即可。

## 调参指南

| 参数 | 位置 | 说明 |
|------|------|------|
| `VISION_AREA_NEAR`（默认 10000） | main.c 顶部 | 手掌 30~40cm 时的面积，达到即停车 |
| `VISION_AREA_FAR`（默认 3000） | main.c 顶部 | 中远距离分界，小于则全速接近 |
| 速度档 0 / 1.5 / 2.5 | main.c 视觉控制块 | 参考遥控器尺度（满摇杆≈4） |
| 转向增益 `÷25` | main.c 视觉控制块 | 转向方向反了把 `(VisionX - 160)` 改为 `(160 - VisionX)` |
| 帧差阈值 30 | frame_diff_test.ino | 漏检降 15，误报升 40~50 |

调参方法：串口接板上 TX 口（115200）观察 `VX:xxx VA:xxxx` 打印，记录手掌在各距离的面积后填入阈值。
