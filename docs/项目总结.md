# 项目总结：基于 ESP32-S3 CAM 的手掌追踪自平衡车

> 2026 年暑期 · 个人项目 · 已实测通过

## 一、项目概述

**目标**：为两轮自平衡车装上"眼睛"，使其能够锁定并跟随人的手掌——手掌在 30~40cm 处停车对正，更远自动接近，目标移出画面则原地静止等待。

**成果**：ESP32-S3 CAM 视觉前端（帧差法 + BFS 连通域 + 卡尔曼多目标追踪）+ STM32 主控视觉外环（目标锁定 + 面积定速 + 质心转向），通过 UART 115200 实时联动，全程无第三方算法库依赖，核心算法均为独立实现。

## 二、系统组成

| 模块 | 硬件 | 软件职责 |
|------|------|----------|
| 视觉前端 | ESP32-S3 CAM（GC2145） | 320×240 灰度 → 帧差 → 160×120 降采样 → 连通域 → 卡尔曼跟踪 → 串口输出 |
| 主控 | STM32F103C8T6（江协平衡车板） | 串口中断解析 → 目标锁定 → 视觉外环 → 原有串级 PID → 电机 |
| 通信 | 单线 UART + 共地 | `MOTION:n;id,x,y,area,miss` 协议，115200，约 30fps |
| 交互 | 按键/遥控/OLED | K1 启停平衡，K2 切换遥控/视觉模式 |

## 三、关键技术

1. **帧差法运动检测**：逐像素帧间差分 + 阈值二值化，2×2 降采样把内存占用从 75KB 压到 19KB，同时计算量降为 1/4
2. **BFS 洪泛连通域**：4 邻域广度优先搜索聚类运动像素，整格容量静态队列杜绝越界，面积滤波滤除噪声
3. **卡尔曼多目标跟踪**：恒速模型 + 标量增益，先取新息再修正位置（保证速度估计不偏），最近邻关联 + miss 生命周期管理，支持 1~3 个目标 ID 稳定跟踪
4. **视觉外环与串级 PID 融合**：视觉只写速度环/转向环目标值，与原"速度环→角度环"串级结构完全复用；面积（∝1/距离²）分档定速 + 滞回防抖，转向增益与遥控同尺度
5. **系统鲁棒性设计**：300ms 视觉掉线保护、面积 uint32 防溢出、GPIO 矩阵重映射解决引脚冲突、摄像头掉线自动重启（CAM_RESTART）

## 四、开发过程与关键问题

| # | 问题 | 定位 | 解决 |
|---|------|------|------|
| 1 | 挥手即随机重启、ID 乱跳 | BFS 队列仅 150 格且入队无边界检查，运动区域远超容量导致栈越界 | 整格容量静态队列 + 严格边界检查 |
| 2 | 反复重启（DRAM 溢出） | 帧缓冲与工作数组挤占内部 RAM | 降采样网格 + 帧缓冲强制放 PSRAM |
| 3 | 板载仅 SDA/SCL 四针口可用 | 视觉模块无外露串口脚 | 查官方例程证实 GPIO47/48 空闲，GPIO 矩阵重映射为 UART |
| 4 | STM32 锁不住目标 | 协议字段不匹配（缺面积字段） | 统一 5 字段格式，面积用于距离估计 |
| 5 | 摄像头运行数秒停摆（4 秒周期 FB_ERR） | 电脑 USB 供电不足，传感器轨电压跌落 | 5V 2A 独立供电 + XCLK 降频降功耗 + 软件自愈 |
| 6 | 追踪"原地等待"不动 | 速度目标按手掌尺度偏小一个数量级 | 改用遥控器同尺度分档 + 串口实测 VA 值校准阈值 |

**调试方法论**：先分模块验证（ESP32 串口数据 → STM32 解析 → 控制输出），再整体联调；每个故障点都从"现象 → 数据证据 → 根因"链式定位，不靠猜。

| 验证项 | 结果 |
|--------|------|

| 多目标（1~3 个）检测，ID 保持稳定 | ✅ |
| 目标丢失 miss 递增至 8 自动清除 | ✅ |
| STM32 115200 稳定解析，300ms 掉线保护生效 | ✅ |
| 手掌 30~40cm 停车对正，更远自动接近 | ✅ |
| 无目标原地静止等待，遥控/视觉模式互不干扰 | ✅ |
