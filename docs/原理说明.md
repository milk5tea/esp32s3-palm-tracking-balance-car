# 技术原理说明

## 1. 视觉感知：帧差法

- 摄像头输出 320×240 灰度图，与上一帧逐像素做差：`|F(t) - F(t-1)| > 阈值(30)` 判定为运动像素
- 2×2 降采样到 160×120 网格（内存 75KB→19KB，计算量 ÷4）
- 特性：只能看见"动"的东西——目标保持轻微晃动即可持续被检测

## 2. 连通域分析：BFS 洪泛填充

- 对二值运动掩膜做 4 邻域 BFS，把相邻运动像素聚成团块
- 面积 ≥ 80px² 才算有效目标（滤除噪声）
- 质心 = 团块像素坐标均值，映射回 320×240 坐标
- 队列按整格容量（19200）静态分配，绝无越界（早期版本的队列上限 150 曾导致挥手即崩溃/ID 乱跳）

## 3. 多目标跟踪：卡尔曼滤波 + 最近邻关联

- 每个目标一个恒速模型卡尔曼跟踪器（标量增益简化版）：
  - 预测步 `x += vx, P += Q`；更新步 `K = P/(P+R), x += K·(mx-x)`，速度由新息更新
  - 新息必须在位置修正**之前**提取，否则被增益吃掉导致速度估计偏小
- 关联：当前帧团块与已有跟踪器最近邻匹配（曼哈顿距离 < 50px）
- 生命周期：匹配上 miss 清零；连续 8 帧未匹配则删除；新团块分配递增 ID
- 能力：1~3 个运动目标同时跟踪，ID 稳定；目标短暂遮挡靠预测撑住

## 4. 通信协议

```
MOTION:n;id,x,y,area,miss;id,x,y,area,miss;...
```

| 字段 | 含义 |
|------|------|
| n | 当前目标数 |
| id | 目标编号（递增，永不重复） |
| x, y | 质心坐标（0~320 / 0~240，左上原点） |
| area | 面积（px²，最大 76800，用于距离估计） |
| miss | 连续丢失帧数 |

115200 波特率，约 33ms 一帧。STM32 在 USART1 中断内逐字节接收、按行解析。

## 5. STM32 控制：视觉外环 + 串级 PID

- **目标锁定**：锁定目标 miss<5 维持锁定；丢失后选面积最大者重锁；300ms 无数据判视觉掉线
- **距离控制**（面积 ∝ 1/距离²）：
  - VA ≥ NEAR（30~40cm）→ 停车，仅转向对正（带 0.8 倍滞回防抖）
  - FAR ≤ VA < NEAR → 中速接近（1.5）
  - VA < FAR → 全速接近（2.5）
- **转向控制**：`TurnPID.Target = (VisionX - 160) / 25`，限幅 ±4（与遥控满摇杆同量级）
- **与原系统衔接**：视觉外环只写 `SpeedPID.Target` / `TurnPID.Target`，原有 速度环→角度环 串级结构与遥控模式完全复用；视觉模式下遥控/蓝牙摇杆自动失效（防打架）
- **安全**：无目标原地静止等待；面积类型 uint32 防溢出误判；视觉掉线 300ms 自动清目标
