# 接线说明

## 1. 视觉模块 ↔ 平衡车板

视觉模块（幻尔 ESP32-S3 CAM）只有一个四针口：**SDA / SCL / GND / 5V**。其中 SDA=GPIO47、SCL=GPIO48（官方例程 `iic_data_send.cpp` 证实），固件已将 GPIO47 通过 GPIO 矩阵重映射为串口 TX。

| 视觉模块四针口 | 接平衡车板 | 说明 |
|----------------|------------|------|
| **SDA**（GPIO47，固件重映射为 UART TX） | 板上 **RX** 口（PA10，USART1） | 数据线：MOTION 数据 115200 |
| **GND** | 板上 GND | 必须共地 |
| **5V** | 5V 供电 | 独立 5V 2A（充电头）或车稳 5V；**不要接板上 3.3V** |
| SCL（GPIO48） | 不接 | — |

注意事项：

- 板上 TX/RX/GND/3.3V 四针口即 USART1（PA9/PA10），与调试打印共用，波特率统一 115200
- 调试打印接 USB-TTL 到板上 TX（PA9）即可看 `VX/VA` 数据
- 供电不稳的表现：FB_ERR 循环（4 秒一次）、POWERON 重启——换短粗线 / 机箱后置口 / 手机充电头

## 2. 平衡车板其他外设（未改动）

| 外设 | 引脚 |
|------|------|
| OLED + MPU6050 | 软件 I2C：PB10(SCL)/PB11(SDA)，OLED 另有 PB8/PB9 |
| 蓝牙 | USART2 PA2/PA3（9600） |
| NRF24L01 遥控 | 软件 SPI：PA8/PA15/PB3/PB4/PB5 |
| 电机方向 | PB12~PB15 |
| 电机 PWM | PA0/PA1（TIM2） |
| 编码器 | PB6/PB7（TIM4） |
| 按键 | K1=PB1，K2=PB0，K3=PA5，K4=PA4 |
| LED | PC13 |

## 3. 调试接线

- **电脑看 ESP32**：USB 线直连视觉模块（串口监视器 115200，含 MOTION 回显，`MOTION_ECHO_USB` 开关控制）
- **电脑看 STM32**：USB-TTL 接板上 TX（PA9）+ GND，串口助手 115200，视觉模式每秒打印 `VX:xxx VA:xxxx`
- **手机上蓝牙调 PID**：原有蓝牙串口功能不变
