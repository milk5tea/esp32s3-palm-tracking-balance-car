# frame_diff_test — ESP32-S3 CAM 帧差法 + 卡尔曼多目标追踪验证

纯串口输出（115200），不联网。

## 环境

- 开发板：**ESP32-S3 CAM**（引脚按通用 Freenove 布局）
- Arduino 板型选择：ESP32S3 Dev Module（或你之前跑通图传用的板型）
- Tools 菜单：**PSRAM 选 OPI PSRAM**（摄像头帧缓冲放 PSRAM 的关键，不开会内部 RAM 溢出）
- 波特率：115200

## 烧录

1. Arduino IDE 打开 `frame_diff_test.ino`
2. 板型、PSRAM 选好后编译烧录（S3 板一般自带 USB 串口芯片，直接烧即可）
3. 烧录完成后按一下 RST

## 与 STM32 平衡车接线（MOTION 数据走板载 SDA 口）

板载 4 针口实测 SDA=GPIO47、SCL=GPIO48（官方例程 iic_data_send.cpp 证实）：

| 板载口 | 接法 |
|--------|------|
| SDA（GPIO47） | → STM32 的 **PB11**（USART3 RX） |
| GND | → STM32 的 GND（共地） |
| 5V | → 车上 5V（给摄像头供电） |
| SCL（GPIO48） | 不用接 |

USB 串口监视器仍可看调试信息（`Frame Diff Test Start`、`FB_ERR` 等），MOTION 数据不再从 USB 出。

## 验证步骤

1. **上电看串口**：应看到 `Frame Diff Test Start`，然后稳定刷 `MOTION:0`（约每 33ms 一条）。→ 目标1：不卡死、不重启
2. **实验1 挥手**：手在镜头前左右挥动 → `MOTION:1;0,x,y,面积,0`，ID 保持 0，坐标平滑跟随 → 目标2/3
3. **实验2 两根手指**：两根手指在画面不同位置移动 → 出现 2 个不同 ID
4. **实验3 目标消失**：手移出画面 → miss 从 0 递增到 8 后目标被删除，回到 `MOTION:0`

## 通过标准

| 验证项 | 标准 |
|--------|------|
| 串口持续输出 MOTION | 不卡死、不重启 |
| 挥手检测到 1 个目标 | ID 保持稳定，坐标跟随变化 |
| 多目标检测 | 出现 2~3 个不同 ID |
| 目标丢失后消失 | miss 值增长后自动清除 |
| 帧率 | 输出节奏平稳，约每 33ms 一条 |

## 与原方案的差异（已修正的问题）

1. **修复 BFS 队列越界**：原代码栈上 `qx/qy[150]`，入队无边界检查——手一进画面（运动区域远超 150 格）就写穿栈，导致随机重启；且连通域被截断，一只手会被切成多个目标、ID 乱跳。现改为整格容量（160×120=19200）的静态队列，每个格子最多入队一次，不可能越界。
2. **修复速度更新残差**：原代码在位置修正之后再算速度，新息被增益 K 吃掉约 80%，速度估计偏小 5 倍。现改为先取新息再修正。
3. **帧缓冲按 PSRAM 情况自动选位置**（`CAMERA_FB_IN_PSRAM`），避免内部 DRAM 溢出。
4. **帧差直接降采样到 160×120 网格**：diff 数组 75KB → 19KB，连通域计算量降为 1/4。
5. **相机初始化失败打印错误码**（`CAM_INIT_ERR: 0x...`），替代无限 `FB_ERR`。
6. miss 达到 `MAX_MISS`(8) 即删除目标（原代码 `>8` 才删，与验证文档描述对齐）。
7. 输出格式增加面积字段：`MOTION:n;id,x,y,area,miss`（STM32 平衡车侧用它估算目标距离，**需重新烧录 ESP32**）。
8. MOTION 输出改走板载 SDA 口（GPIO47）的硬件串口，USB 串口留作调试（板子只有 SDA/SCL/GND/5V 四针可用，官方例程证实这两脚空闲）。

## 坑

| 现象 | 原因 | 解决 |
|------|------|------|
| 一直 MOTION:0，手在动也检测不到 | 阈值太高或光线太暗 | `DIFF_THRESHOLD` 30 → 15 |
| 没东西动也报 MOTION:3/4 | 阈值太低或光线闪烁 | 阈值升到 40~50 |
| 串口乱码 | 波特率不对 | 确认 115200 |
| 运行几十秒后重启 | 供电不足 | 换 5V 2A 电源 |
| FB_ERR 频繁 | 摄像头初始化失败 | 检查排线插紧、供电 |
| CAM_INIT_ERR: 0x105 | 找不到摄像头 | 核对引脚布局（README 顶部引脚表） |
| 目标 ID 频繁变化 | 匹配距离太小 | loop() 里 `best_d` 从 50 改成 80 |
